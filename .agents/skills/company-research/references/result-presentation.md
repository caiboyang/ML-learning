# 公司研究结果的组织与呈现

本文件只定义阅读结构、图表与版式。分析深度和内容验收由 [研究合同](research-contract.md) 定义；字段、导出与运行验证由 [数据约定](dashboard-data.md) 定义。先设计读者怎样看结果，再编排正文。

## 阅读路径与议程

| 阅读任务 | 应先看到什么 | 怎样继续 |
| --- | --- | --- |
| 快速判断 | 对象、时期、问题、主判断、关键指标与主要未知 | 从结论进入对应主节 |
| 理解与比较 | 完整产物、动作路径、机制及横向差异 | 进入补充论证和逐家案例 |
| 核实与执行 | 就近口径、来源、反证与下一调查 | 返回相关记录、回答问题并更新判断 |

议程按“研究对象本身 → 决策与下一步 → 公司对标 → 证据”排序。主目录采用扁平编号、具体产物名称，不把覆盖框架或每条记录变成菜单。外部研究可使用：执行结论、现状、产品盘点、渠道盘点、起步资产、团队与分工、自身路径、自身回路、关键决策、衰退诊断（适用时）、借鉴顺序、下一步调查、横向对照、证据库。节数随问题调整，不固定凑十四节。

正文与目录同序。1280×900 下应能一屏扫完主目录；先缩短标签、合并相同判断任务，不能缩小字体来硬塞。较矮窗口允许导航滚动。窄屏折叠同一目录，回到宽屏自动展开；当前章节只高亮主节，不列记录子目录。

## 主页面与专题分工

**主页面必须完整呈现每个主节的产物，每个条目都可见；条目可以精炼，不能搬走。** 每节采用“论点 → 完整结构化产物 → 结论与边界 → 可选深挖入口”。默认不折叠影响判断的内容；只有主动筛选才改变可见范围。

论点是对本次研究对象的一句可由证据支持或推翻的判断，可以带条件；不能只说本节列了什么、如何排列或重复标题。结论写这项判断对选择或下一调查的意义。限制具体到每条记录的证据、窗口或样本，不能用相同套话代替实际边界。证据允许时写暂定解释及反证；无法区分解释时明确分歧与区分证据，不强行选一个“最可能”。

完整性按语义验收：证明状态有全部命题，路径有全部关键步骤，历史复盘有全部关键选择，回路有全部反馈边，建议、路线与行动有全部条目，下一轮数据约定和横向矩阵也留在主页面。按[案例合同](research-contract.md#重点公司专题的最低结构)选择的重点对标独立成节，其关键步骤全部在主页面可读；材料不足时显式保留覆盖缺口。产品、渠道、资产和团队不能只留下一个摘要标题。

子页用于**增加分析深度**，不以条目数量作为拆页理由。判断是否需要子页，应看是否有值得独立解释的口径、推导、反证或案例；仅把现有列表换个页面不算深挖。

| 主节完整产物 | 子页补充什么 |
| --- | --- |
| 全部证明命题及状态 | 同批漏斗与分支、分母和窗口、对账、判断变化、下一轮字段 |
| 全部建议或路线 | 四道门槛如何改变选择、会议需要确认什么及依据 |
| 目标公司或重点案例的完整路径 | 创始人与互补资产、首次交付及人工验证、失败尝试、取舍与迁移条件 |
| 全部对照矩阵行 | 每家公司按研究合同的同一结构拆解，再比较机制差异 |
| 全部历史决策 | 当时可知信息的时间边界、构造备选、替代解释和反证 |

子页扩展一个明确主节，首屏有父节返回与一行论证路线，正文使用 3–6 个论证模块，不设侧栏。顶部入口按研究对象与公司对标分组；末尾回到验证或下一步调查。记录和数字可复用同一 ID，同时出现于主页面与子页；同一视图不重复放同一条记录。补充序列、漏斗、计算、判断变更和普通对标的逐步档案可以只在子页。

## 表达形式与证据边界

| 判断任务 | 优先形式 | 保留的信息 |
| --- | --- | --- |
| 阶段与证明 | 命题／状态／证据／缺口／下一步表 | 不适用有原因，未知与反证分开 |
| 产品、渠道、资源、团队 | 同字段表或卡片 | 角色、控制者、投入、时期、验证强度、责任与来源 |
| 公司或路线比较 | 同字段矩阵 | 相近阶段、可调用资产、结果、限制；无定义不评分 |
| 行为路径与历史选择 | 时间线与决定条目 | 日期、事实动作、当时信息、后续结果、复盘解释 |
| 交付与转化 | 流程或同批漏斗 | 事件、窗口、分母；复用与转供给有重叠时画分支 |
| 增长反馈 | 回路图或逐边表 | 每条边的作用、回流方式与证据状态 |
| 趋势与留存 | 序列表、批次表或热图 | 单位、时间、口径变化、未成熟批次；缺失不是零 |
| 收入与成本 | 拆解表或情景表 | 假设、费用范围、区间；估算不冒充利润 |
| 建议与行动 | 采纳看板、路线卡、里程碑表 | 分类、条件、责任、观察、继续与停止标准 |

图形解释关系，表格便于查阅，正文讲清原因。不要把所有内容切成同样卡片，也不要重复绘制相同数字。未知数据用明确文字；缺口的显著程度应与其决策影响相称。

## 版式与视觉层级

```text
首屏：标题／对象／时期／截止日 → 主判断／边界 → 关键指标
导航：主页面左侧扁平目录；顶部按对象分组的专题入口
主区：论点 → 完整产物 → 结论与限制 → 可选补充分析
子页：返回父节 → 论证路线 → 3–6 个模块 → 下一步
```

保留深色导航和浅色阅读区。桌面目录约 260–288 px、主区留白 24–32 px；连续中文正文约 35–45 字一行，矩阵可更宽。正文 16–18 px、行高 1.6–1.8；标题、章节标题、正文、口径依次降低层级，来源仍须可读。块间 16–24 px，节间 40–56 px。数值是可调整的起点，不凌驾于已有设计系统。

同类条目字段顺序一致。卡片通常不超过三列，文本多时用表格或分节；数字同单位右对齐。青色用于当前选择或链接，事实／解释／建议、采纳状态分别配文字标签，颜色不能独自传达含义。避免装饰性评分、厚重阴影与渐变。

窄屏按原顺序堆叠；宽表局部滚动，不能撑宽整页或缩字。固定栏不得遮挡锚点，跳转后焦点可辨识。打印保留日期、范围、筛选与来源；文字版也保留口径和限制。只交付一种格式时只维护该格式。

## 定位、追证与交互

重要判断、数字、问题和行动使用稳定标识，能从结论到具体来源，也能从来源回到使用它的记录。来源明细包含时间、位置、支持范围与局限；不是页尾一串裸链接。主页面、矩阵和子页共享数据，更新规则见 [研究合同的判断更新](research-contract.md#下一轮经营数据合同)。

筛选服务于比较和核实：明示当前公司、搜索与性质的组合条件，以及首屏摘要、证据区是否受影响。事实筛选不能隐藏事实所需口径与限制。显示结果数、空状态和重置；深链应恢复必要筛选、切到包含记录的页面并聚焦。少量内容无需强行增加筛选。

静态页面只能显示已记录问答，不能暗示它会保存输入或自动研究。证据库前完整展示覆盖清单，包括状态、关联记录和缺口；它说明整份研究的完成程度，不随正文筛选变化。具体搜索范围、字段过滤与路由行为见 [数据约定](dashboard-data.md#视图与更新约定)。

## 展示验收

- 只读首屏与章节结论，能复述问题、主判断、边界和下一步。
- 不打开子页、不操作折叠，能找到每项主产物；不能只通过“有子页入口”验收完整性。
- 子页确实增加口径、推理或证据分析，并有父节、来源和行动返回。
- 沿一个关键数字查到来源、定义与反证，再返回原记录；沿矩阵进入每家对标的完整拆解。
- 1280×900、390×844 下目录、典型中段、宽表、证据区、长文本、键盘和空结果可读可用。
- 内容深度另按 [研究合同覆盖清单](research-contract.md#内容覆盖清单交付时逐项填写) 验收；导出、离线和可复现测试另按 [数据约定](dashboard-data.md#验收) 执行。
