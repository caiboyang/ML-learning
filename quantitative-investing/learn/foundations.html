01 / 06 · RETURN约 5 分钟

先把钱，变成能比较的量。

赚 1 万和赚 100，谁更厉害？缺少本金和时间，问题还没定义完整。

本期收益率 r = 本期盈亏 / 期初价值
= (期末价值 − 期初价值) / 期初价值

若单独收到现金分红，也要计入收益。这里先假设没有外部存取款；真实账户的入金不能当成盈利。

为什么还要减去一个基准？

测试一个系统时，你会先定义 baseline。金融里至少有两种不同的对照，不能看到“超额”两个字就把它们混在一起。

要回答的问题算哪个差本月教学例子
承担投资风险，比短期无风险参照多赚多少？r − rf，本文称无风险超额收益3.2% − 0.2% = 3.0 个百分点
比选定的大盘或对照策略多赚多少？r − rb，主动收益3.2% − 2.2% = 1.0 个百分点

r 是本期资产收益；rf 是同币种、匹配周期的无风险参照收益；rb 是所选基准收益。“无风险”是模型参照口径，不能把任意期限的国债都当成持有期内价格不变。

两个常见单位错误：复利与 bp

两期收益要相乘：100 先涨 10% 到 110，再跌 10% 到 99。累计是 −1%，不是 0%。

累计收益 = (1 + r₁)(1 + r₂)…(1 + rₙ) − 1
CAGR = (期末价值 / 期初价值)^(1 / 年数) − 1

CAGR 是把实际路径折算成恒定年增长率，不保留中途的颠簸。算式仍假设没有外部现金流。

1 bp（基点）= 0.01 个百分点 = 0.0001。收益从 5% 到 6%，提高 1 个百分点，也就是 100 bp；相对原来的 5% 则增加了 20%。写代码时，10% 通常输入为 0.10。

自测：策略赚 3.2%，大盘赚 2.2%，alpha 就是 1% 吗？
只能先算出主动收益 1 个百分点。还不知道策略承担了多少市场暴露；先看下一节的 beta，再计算模型调整后的 alpha。

基础阅读：Shiller：Risk and Financial Crises；无风险参照与超额收益口径参见 Damodaran，第 4 章。本节算例为原创。

02 / 06 · BETA β约 7 分钟

Beta：市场动一格，
拟合的收益动几格？

把每个月的市场超额收益当输入 x，把策略超额收益当输出 y，先拟合一条直线。beta 就是斜率。

输入 x市场收益 − 无风险收益
→
线性模型y 的拟合值 = α + βx
→
观察到的 y拟合值 + 当期残差 ε

这和工程里的增益很像：β = 1.5，表示 x 增加 1 个百分点，直线上的 y 增加 1.5 个百分点。它描述数据中的线性关系；不是每次都精确跟随，也不是市场对个股的因果传递函数。

查看／保存 alpha 与 beta 静态对照图 ↗

人们为什么要用 beta？

实际问题beta 提供的信息仍然缺什么
组合会不会太依赖市场上涨？市场敏感度；固定权重下组合 β 是各资产 β 的加权和个股事件、非线性风险、估计误差
这个经理只是把市场放大了吗？把 β × 市场超额收益单独算出来其他风格、成本与真正的样本外表现
“高 beta 股”是什么意思？通常指相对所选市场基准 β 较高；β > 1 常用作直观界线采用什么指数、多久窗口、日频还是月频

“高 beta 股”是敏感度描述，不是 A 股、B 股那样的市场分类。β = 0 只说明没有这条线性暴露；公司仍可能因自身事件暴涨暴跌。负 β 表示拟合关系方向相反。

工程推导：为什么是 Cov(x,y) / Var(x)？

从最小二乘开始：选择截距 a 和斜率 b，让所有点到直线的纵向残差平方和最小。

L(a,b) = Σ[yₜ − a − bxₜ]²
∂L/∂a = 0 → a = 平均 y − b·平均 x
∂L/∂b = 0 → b = Σ[(xₜ−平均 x)(yₜ−平均 y)] / Σ(xₜ−平均 x)²
所以 β̂ = Cov(x,y) / Var(x)
α̂ = 平均 y − β̂·平均 x

分子统计“输入偏大时，输出是否也偏大”；分母除去输入自己的变化幅度。用同一分母定义样本协方差和方差，n−1 会约掉。如果 x 完全不动，分母为 0，无法辨认斜率。帽子 ^ 表示从样本估计。

β = ρ(x,y) × σ_y / σ_x

相关系数 ρ 衡量线性同步程度，范围 −1 到 1；β 还包含输出／输入的波动幅度比，所以可以大于 1。若 σ_y = 30%、σ_x = 20%、ρ = 0.5，则 β = 0.75；不能直接用 30/20 得到 1.5。

本页含截距的单变量 OLS 中，R² = 1 − 残差平方和 / y 的离均差平方和。它说明这条线在这批样本中解释了多少变动，不是预测准确率，也不是赚钱概率。

自测：β = 2，大盘的超额收益为 −3%，意味着什么？
模型里的市场暴露项是 2 × (−3%) = −6%。实际策略收益还要加回无风险收益、alpha 和当期残差，不能断言实际一定亏 6%。

定义核对：Damodaran：beta 的归一化与市场风险；回归、截距与估计误差。旋钮、数据与推导编排为本教程原创。

03 / 06 · ALPHA α约 6 分钟

Alpha：解释完共同来源，
平均还剩多少？

“策略涨得比市场多”只是现象。先问它承担了多少市场敏感度，才能进一步讨论额外表现。

一个月的教学账本：无风险收益 0.2%，市场总收益 2.2%，策略总收益 3.2%。假设此前拟合的 β = 1.5。

市场超额：2.0%2.2% − 0.2%
→
市场暴露项：3.0%1.5 × 2.0%
→
加回现金：3.2%0.2% + 3.0%

策略比市场多赚了 1 个百分点，但它的 3.2% 已可由“现金参照 + 市场暴露”解释。这一期模型调整后的剩余收益是 0。

四个部件，拼出实际收益

rₜ = rf,t + β(rm,t − rf,t) + α + εₜ
部件工程直觉在比较什么
rf,t基线同一期的无风险参照收益
β × 市场超额收益输入乘响应系数市场暴露能解释的部分
α截距这套模型未解释的平均收益部分
εₜ当次误差这个月相对拟合值的偏离

一个月的剩余是 α + εₜ，不能直接当成稳定的 alpha。有多期数据后，含截距 OLS 的样本残差平均为 0，于是 α̂ = 平均策略超额收益 − β̂ × 平均市场超额收益。

如果月度回归得到 α̂ = +0.5%，它是这段样本、这个市场模型下的月度截距估计。它不表示每个月必赚 0.5%，也不表示下个月的 alpha 已知。

为什么业界喜欢讨论 alpha？

因为要区分“持有某类市场风险带来的收益”和“模型调整后还剩的表现”。这会影响是否值得付管理费、一个新策略是否增加了不同的收益来源。它把“我很厉害”变成可检验的主张。

进一层：alpha 为什么会随模型改变？

假设一个策略偏爱便宜的小公司。只放市场收益进回归，这种风格的平均收益可能进入截距；再加入规模和价值因子的收益，部分原来的 alpha 可能被解释掉。

单因子：y = α + β_M·市场因子 + ε
多因子：y = α + β_M·市场因子 + β_S·规模因子 + β_H·价值因子 + ε

因此正 alpha 可能来自能力，也可能来自遗漏因素、运气、漏算成本或选择了漂亮样本。它是模型相对量；不是经过鉴定的“纯技术收益”。继续看因子三层图 →

再进一层：回归模型与 CAPM 不是同一种结论

回归是在历史散点上拟合关系。CAPM（资本资产定价模型）则在特定市场与投资者假设下，讨论预期收益应如何补偿市场风险：E[r] − r_f = β(E[r_m] − r_f)。E 表示期望，不是已实现的某个月结果。

在这套定价基准下评估截距，就是常说的 Jensen’s alpha。拟合得出 β 并不证明 CAPM 的假设成立。若直接用原始收益拟合 r = a + βr_m，a 也不能不作无风险调整就叫这里的 alpha；本页统一先减 r_f，避免这个混淆。

自测：某月策略跌 2%，市场跌 3%，就能说 alpha 为正吗？
还不够。需要无风险收益、所选模型与 beta。即使算出当月模型调整后的剩余为正，也只有一个 α + ε 的观察值；需要更长样本和不确定性评估。

Jensen’s alpha 及原始／超额收益回归的区别：Damodaran，第 4 章，4.29–4.30。多因子入口：Fama–French（1993）。账本为原创示意。

04 / 06 · VOLATILITY & DRAWDOWN约 5 分钟

同样的平均收益，
走过去的路可能完全不同。

波动率压缩“每期收益围绕均值偏多远”；回撤保留“从之前的最高点跌下来多少”。它们回答不同问题。

为什么要平方再开根号？

直接平均“收益 − 均值”，正负会抵消成 0。平方先把大小留下，再求平均；最后开根号，把单位从“收益率的平方”变回收益率。

样本均值 r̄ = Σrₜ / n
样本方差 s² = Σ(rₜ − r̄)² / (n − 1)
样本标准差 s = √s²

这里使用样本标准差：均值也来自这 n 个观察值，所以常用 n−1 校正样本方差。A 的离均差是 −1、+1、−1、+1 个百分点，s = √(4/3) ≈ 1.15 个百分点。

用绝对值也能定义离散度；平方不是唯一可能的选择。方差便于代数运算和组合风险分解，因而使用广泛。收益率的标准差是这里的波动率，不能拿价格水平的标准差替代。

到 t 为止的峰值 Hₜ = max(V₀,…,Vₜ)
当期回撤 Dₜ = 1 − Vₜ / Hₜ
最大回撤 MDD = max(Dₜ)
指标为什么用它没有告诉你
波动率 σ比较收益的颠簸程度；调整仓位；计算组合风险上下波动都计入；不能单独刻画尾部、流动性或永久损失
最大回撤 MDD了解样本内从峰到谷的资金压力历史最坏值不等于未来损失上限；还要看回撤持续多久
自测：亏 20% 后，涨 20% 能回本吗？
100 → 80 → 96，还没回本。需要 (100−80)/80 = 25% 的上涨。百分比的分母变了。

方差与组合的原始入口：Markowitz（1952）；统计入门：Shiller 的风险课程。序列、图与手算均为原创。

05 / 06 · SHARPE RATIO约 6 分钟

多赚一点，
付出了多少波动？

Sharpe 把超过无风险参照的平均收益，除以这条超额收益序列的标准差。它用于在共同波动尺度下比较策略。

先逐期算 dₜ = rₜ − rf,t
历史 Sharpe = 平均(dₜ) / 样本标准差(dₜ)

像一种“平均信号 / 波动幅度”，但金融里的波动并不全是测量噪声。这是帮助理解的类比，不应把随机收益和电子噪声等同。

为什么它不是“杠杆越大，成绩越好”？

在以同一无风险利率融资、无额外成本且正倍数缩放的理想条件下，超额收益乘 k，标准差也乘 k，所以比值不变。仅把仓位放大，不会凭空改善 Sharpe。

手算一次：从一列数据到 Sharpe

假设四个月的超额收益依次为 0%、2%、0%、2%。均值 1%，样本标准差 √(4/3)% ≈ 1.1547%，所以月度 Sharpe ≈ 0.866。

在稳定、零序列相关的加总近似下：
年化均值 ≈ 12 × 月均值
年化标准差 ≈ √12 × 月标准差
年化 Sharpe ≈ √12 × 月度 Sharpe

收益相加时，均值按期数累加；若不同期不相关，方差也按期数相加，标准差就按平方根增长。四个点只为手算，不足以评价真实策略。存在自相关、时变波动或复利效应时，机械乘 √12 可能误导。

看到一个 Sharpe 数字，追问什么？为什么
周期、样本长度、净收益还是毛收益？不同口径无法直接比较；短样本容易碰巧很漂亮
收益分布有什么形状？偶尔巨亏的策略，平时也可能显示很高 Sharpe
试了多少次才选出它？反复筛选会挑到幸运样本
是回测、留出测试还是实际交易？这些数字承担的证据强度不同
自测：Sharpe = 1，是不是说明“100% 能盈利”？
不是。它只是平均超额收益与标准差的比值；既不是胜率，也不是未来盈利概率。标准差为 0 时也不能照常除；数值未定义不能当成无限可靠。

优先读原作者：William F. Sharpe，《The Sharpe Ratio》（1994），重点是 The Ratio、Time Dependence、Scale Independence。表格与算例为本教程原创。

Signal / Alpha signal对未来收益的打分或交易方向；业界口语也会把它简称 alpha用于排序／持仓；这个用法不是已估计的回归截距
动量 Momentum用过去的相对强弱或自身收益方向构造信号检验延续性；须写清比较对象与观察窗口

价差 Spread两个价格的差，或带对冲比例的组合 P_A − hP_B研究相对价格；h 也常写成 β，但不自动等于市场 beta
z-scorez = (当前值 − 历史均值) / 历史标准差把偏离归一化；z = 2 表示高出两个标准差，不是有 95% 概率回归
市值 / P/E / B/M价格×股数 / 股价÷每股盈利 / 账面权益÷市场权益规模与估值输入；负盈利时 P/E 的简单比较会失去通常含义
流动性 Liquidity在多大规模与多小价格影响下，能完成交易决定规则能否按预期成交
滑点 Slippage实际成交价相对计划／基准价格的偏离把“纸面机会”换成可成交结果；基准口径必须说明

回测 Backtest按历史时序重放规则与成交假设检验假设；结果依赖数据与执行模拟
样本外 OOS没有参与这轮模型与参数选择的数据检查泛化；反复看测试集调参后，它就不再是干净留出
